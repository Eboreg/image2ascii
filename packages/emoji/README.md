## Settings

Settings available in the config YAML file (default on GNU/Linux: `~/.config/image2ascii/config.yaml`):

* `emoji.emoji_dir`: path for emoji SVG files (default on GNU/Linux: `~/.local/share/image2ascii/svg/emojis`)
* `emoji.flag_dir`: path for flag SVG files (default on GNU/Linux: `~/.local/share/image2ascii/svg/flags`)
